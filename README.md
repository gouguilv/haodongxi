
# 石头剪刀布 - 恶搞猜拳游戏

一个带有恶搞趣味的石头剪刀布游戏，包含两个版本：
- **普通版**：经典石头剪刀布游戏（电脑随机出拳）
- **必输版**：无论玩家出什么都会输的“必输”版本，带有嘲讽语气

## 游戏特色

- 😄 **双版本**：主菜单可选择体验“普通猜拳”或“作者生气版（必输）”
- 🎮 **简单交互**：命令行界面，输入手势即可游玩
- 🤖 **随机对局**：普通版电脑完全随机出拳，保证公平
- 🔄 **连续对战**：可以一直玩，直到选择退出
- ❌ **输入验证**：自动处理无效输入（如错别字、多余空格）
- 😈 **恶搞内容**：必输版带有幽默的失败反馈和挑衅对话

## 游戏文件说明

| 文件名 | 说明 |
|--------|------|
| `来玩石头剪刀布.py` | 主程序入口，提供版本选择菜单 |

## 安装和使用

### 方法一：直接运行源码

**前提条件**：Python 3.6 或更高版本

1. 克隆仓库到本地：
   ```bash
   git clone https://github.com/gouguilv/haodongxi.git
   cd haodongxi
运行主程序：

bash
python "来玩石头剪刀布.py"
### 方法二：使用打包后的可执行文件（无需python）
从 Releases 页面下载最新版本的 guessfist.exe，双击即可运行。

游戏操作说明
主菜单
输入 愿意：体验普通猜拳（就算输入愿意你也不需要支付任何费用）

输入 不愿意：进入必输版（作者生气版）

输入 退出：结束整个游戏

猜拳游戏内
输入 石头、剪刀、布 进行对战

输入 退出 返回主菜单（普通版）或触发不同结局（必输版）

开发者自定义
如果你想修改游戏内容（例如调整必输版的嘲讽语句或询问频率），只需编辑对应的 .py 文件即可。

必输版参数调整示例（guessfist_unbreakable.py）：

python
#### 修改每几局询问一次（默认3局）
if rounds % 3 == 0:   # 将3改为其他数字
打包成可执行文件（供开发者参考）
如果你修改了代码并想重新打包成 .exe：

安装 PyInstaller：

bash
pip install pyinstaller
在文件目录下运行：

bash
pyinstaller --onefile --name 猜拳游戏 "来玩石头剪刀布.py"
生成的 猜拳游戏.exe 在 dist 文件夹中。
